# CordMic 1.1.0

This release adds a podcast-style voice chain. It runs in front of noise reduction in every preset and is on by
default. To turn it off, switch off **Settings → Noise & voice → Podcast voice chain**; processing is then
identical to 1.0.0. Settings files from 1.0.0 and earlier load with the chain on, and every other saved value is
kept.

Windows installers and `CordMic.exe` are not Authenticode-signed (the same as previous stables, while SignPath is
not configured). SmartScreen may warn on first run. Verify downloads with the `SHA256SUMS` file attached to this
release.

Android `versionCode` is 26 / `versionName` 1.1.0. The wire version stays 1. A 1.1.0 phone works with a 1.0.0
PC, with the chain always on. A 1.0.0 phone works with a 1.1.0 PC but has no chain of its own (PC Studio still runs it).

The direct USB engine (AOA / WinUSB) remains **Experimental**, **off by default**, and **untested on hardware**.
Automatic mode still uses USB tethering.

## What the chain does

1. **Auto level (gated AGC).** Speech is brought toward about −17 dBFS RMS. The gain holds in pauses and is never
   raised on silence. The room floor is never lifted above −52 dBFS.
2. **Dynamic EQ.** An 80 Hz high-pass, a cut around 250 Hz that applies only when the voice gets boomy, and a de-ess
   around 6.5 kHz that applies only when s sounds get harsh.
3. **Compressor.** A smooth 3:1 soft knee. Short peaks recover quickly; long loud passages recover slowly.
4. **Look-ahead limiter** at −1 dBFS, with 1.0–2.0 ms of look-ahead.
5. **Dereverb.** Room echo tails are reduced with a spectral late-reverb model.
6. **Dialog isolation.** A voice-activity and speech-presence mask lowers sound that is not speech.

Dereverb and dialog isolation share the existing noise-suppression STFT. Each frequency bin keeps the stronger of
the noise and voice masks, never both stacked, so they do not add "musical noise". A thin true-peak guard runs after
noise reduction. Strengths are conservative per preset: Off has no dereverb or dialog isolation and stays the
lowest-latency choice, and PC Studio – whisper keeps both gentle.

On the phone the chain runs only when PC Studio is off. With PC Studio it runs on the PC in front of RNNoise. It
never runs on both sides.

## Latency (48 kHz)

| Preset | Added in 1.1.0 |
|---|---|
| Off | +1.0 ms |
| Phone – light | +1.5 ms (+6.9 ms on phones where Android's own noise suppressor is used) |
| Phone – strong | +2.0 ms |
| PC Studio (any) | +7.4 ms |

## CPU

The full 1.1.0 Strong chain takes under 1 % of one core on the x86-64 build machine. A watchdog drops dereverb and
dialog isolation if the chain needs more than 30 % of real time on a slow phone. No low-end phone was measured for
this release. Per-stage figures are in `docs/dsp/podcast-chain.md`.

## Other changes

- The release workflow no longer fails when SignPath is not configured. The signing jobs are skipped and the
  unsigned release completes.
