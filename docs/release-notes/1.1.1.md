# CordMic 1.1.1

This release makes mic gain manual and keeps the level meter out of the yellow zone. The podcast voice chain from
1.1.0 is otherwise unchanged: it still runs in front of noise reduction in every preset, and it can still be turned
off in **Settings → Noise & voice → Podcast voice chain**.

Windows installers and `CordMic.exe` are not Authenticode-signed (the same as previous stables, while SignPath is
not configured). SmartScreen may warn on first run. Verify downloads with the `SHA256SUMS` file attached to this
release.

Android `versionCode` is 27 / `versionName` 1.1.1. The wire version stays 1. A 1.1.1 phone works with a 1.1.0 or
1.0.0 PC: the legacy gain byte is still 0–24, and a negative value is sent as 0 so an older peer never treats a wrap
as +24 dB. Signed tenths (−24.0 to +24.0) travel in an optional trailing `GainExt` block that older peers ignore. A
1.1.1 PC writes that block on every PING; the phone writes it on a PONG only after it has seen one.

Settings files from 1.1.0 and earlier load with mic gain set to 0 dB. Every other saved value is kept.

The direct USB engine (AOA / WinUSB) remains **Experimental**, **off by default**, and **untested on hardware**.
Automatic mode still uses USB tethering.

## Manual gain

Mic gain is now a user control from −24 to +24 dB, default 0 dB, in 0.5 dB steps (0.1 dB with Shift). The chain
never raises the gain by itself. Peak-aware protection may only turn it down, when a sample peak would meet
−12 dBFS (3 dB below the yellow meter mark at −9 dBFS). The look-ahead limiter and the true-peak guard sit at
−10 dBFS, 1 dB below yellow, as a last-resort net. Compressor makeup is 0 dB, so a 0 dB setting does not reach
yellow on its own. Auto volume, when on, only enables that downward protection; when off, only the limiter and
true-peak guard remain as a net. Quiet speech stays quiet.

The main window, Settings → Sound, and the phone app show a linked gain knob, a slider and a numeric dB readout
next to the level meter. Double-click (or a double-tap on the phone) resets to 0 dB. The wheel and arrow keys move
0.5 dB (Shift: 0.1 dB). While the control is hovered or focused, the wheel adjusts gain and does not scroll the
page.
