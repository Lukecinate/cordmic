# CordMic 1.0.0

This is the first supported stable release after 0.7.2, and it is the GitHub
latest release. The in-app updater offers it to 0.7.2 and to 0.8.0-beta
installs. Settings from those versions load here.

The version is 1.0.0, not 0.8.0. 0.8.0 as a stable would imply that the USB
accessory (AOA) hardware gates had passed. They have not.
`UsbEngineGate.HardwareGateGm1Passed` stays false. Automatic mode still uses
USB tethering. The direct USB engine from the 0.8.0 betas remains
**Experimental**, **off by default**, and **untested on hardware**.

Windows installers and `CordMic.exe` are not Authenticode-signed (same as
previous stables, while SignPath is not configured). SmartScreen may warn
on first run. Verify downloads with `SHA256SUMS` attached to this release.

Android `versionCode` is 25 / `versionName` 1.0.0. Wire version stays 1.

## Changes

- The Settings pages on the Windows app scroll with the mouse wheel from any
  control on the page (not only sliders or combo boxes). Page Up and Page
  Down also scroll.
- The installer is built with official NSIS 3.13 (fixes CVE-2026-42171 in
  the 3.11 exehead).
- Self-contained Windows builds include the .NET 8.0.34 runtime (November
  2026 patches).
- The updater refuses non-HTTPS asset URLs. SHA-256 verification is
  unchanged.
