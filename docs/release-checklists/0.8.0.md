# Gate H — 0.8.0 hardware checklist

This checklist **blocks** publishing 0.8.0-beta as a *stable* 0.8.0, and any
release marked latest. Tick an item only after you have run it, with the date
and the result. The `tools/release/verify-gate-h.sh` script refuses to publish
a stable release while any box is unchecked.

Audio quality and underrun numbers in the app are **provisional** until the
recordings and bench rows below are complete. Do not lock those thresholds early.

Latency budget (one number, used for MIDI M-3, product G3, and this beta):
measured the same day on the same cable, USB one-way added latency
**median ≤ tethering + 2 ms**, **p95 ≤ tethering + 10 ms**.

"Replug needed" (the app asked to unplug, replug, then turn on USB tethering)
is a **failure**. Target: **0 in 30** armed plug-in sessions. More than **1 in 30**
blocks this gate.

Do not disable Secure Boot, Memory Integrity, Driver Signature Enforcement, or
antivirus in order to pass an item.
