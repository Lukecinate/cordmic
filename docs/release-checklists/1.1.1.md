# 1.1.1 release checklist

- [x] Mic gain is manual, −24 to +24 dB, default 0 dB; existing settings migrate to 0 dB (Windows schema 4, Android prefsVersion 4).
- [x] The chain never auto-raises gain; peak-aware protection may only reduce it (ceiling −12 dBFS). DeviceTune / auto-optimize do not change gain.
- [x] Compressor makeup 0 dB; limiter and true-peak guard at −10 dBFS (1 dB below the yellow meter mark at −9 dBFS sample peak, both platforms).
- [x] UI: linked knob, slider and numeric readout on the PC main window (beside the level meter), Settings → Sound, and the phone app, with the same range and default. Double-click / double-tap resets to 0; wheel and arrows 0.5 dB (Shift: 0.1 dB); keyboard and screen-reader names in EN/ID. Wheel over a hovered or focused control does not scroll the page.
- [x] Wire version stays 1. Optional `GainExt` (0xC9, int16 tenths) on PING always and on PONG only after the peer sent one; legacy byte 0–24, negatives sent as 0.
- [x] Unit tests: default 0 dB, negative range, no auto-boost, loud and full-scale input stays below yellow, typical speech stays in green, knob/slider model stays in sync, GainExt round-trip and 1.1.0 PONG compatibility. Android screenshots use TEST-NET example addresses (`192.0.2.0/24`).
- [x] Original MIT code only; no models, weights or third-party DSP code.
- [x] Android versionCode 27 / versionName 1.1.1; app 1.1.1; wire version 1.
- [x] `UsbEngineGate.HardwareGateGm1Passed` remains false; USB stays Experimental and off.
- [x] CI and CodeQL green on the release commit before the tag; tag `v1.1.1` is new; no tag moved.
- [x] SignPath jobs stay gated off (`SIGNPATH_ENABLED` not set); unsigned Windows build.
- [x] Release assets match `SHA256SUMS`; `/releases/latest` points at `v1.1.1`.
- [ ] Maintainer: listen-test that speech stays out of the yellow zone at 0 dB, and that negative gain and the knob/slider feel right on a 14-inch display at 150–200% scaling.
