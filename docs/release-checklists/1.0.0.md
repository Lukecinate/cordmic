# 1.0.0 release checklist

This is the supported tethering stable. It is **not** blocked on Gate H.

- [x] `UsbEngineGate.HardwareGateGm1Passed` remains `false`. Do not tick Gate H.
- [x] USB / AOA stays Experimental and off by default. Auto stays tethering.
- [x] README (EN/ID), CHANGELOG, and release notes say USB is experimental
      and untested on hardware.
- [x] Updater `ShouldOffer` is true for 0.7.2 and 0.8.0-beta.1–beta.3 when
      latest is v1.0.0, false for 1.0.0 itself and for prereleases.
- [x] Settings from 0.7.2 and 0.8.0 betas load; experimental USB stays off
      unless the user already enabled it.
- [x] CI green on the release commit before the tag is created.
- [x] Tag `v1.0.0` is new; existing tags are not moved.
- [ ] SignPath is used only if the organisation and secrets are already
      available. Otherwise ship unsigned, like 0.7.2, and say so.
- [ ] Release assets (Setup, Portable, APK, SHA256SUMS) match the published
      checksums; `/releases/latest` points at `v1.0.0`.

Hardware evidence, SignPath submit, keystore backup, and company-deploy
review remain maintainer steps and are not part of this checklist's pass.
